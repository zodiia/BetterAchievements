# Recollection

Keep track of achievements and collections in FFXIV. Quickly see your progress in an achievement, or how to obtain that mount you really wanna get.

Currently in active development, please report bugs directly to me.

## Features

- Display every achievements and collectable item in a neat, easy-to-use UI
- Search anything based on names, descriptions, locations, etc...
- Keep track of progress in any achievement
- Automatically update achievement progress (currently supported in a very limited set of achievements)
- Quickly see how to obtain any collection item

## Commands

- `/recollection` - Open the Recollection interface
- `/rec` - Alias for `/recollection`
- `/recs` - Open Recollection directly to the settings
