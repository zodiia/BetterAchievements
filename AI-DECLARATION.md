## Notes

### General usage

Outside of UI (see below), AI was primarily used for research and for understanding more advanced C# features (as I had
done very little C# before this), when search engines were incapable of giving me decent results. It was also very
occasionally used for reviewing a portion of code.

### UI

Some of the purely UI code was written by AI on free tiers. However, anything that was written by AI was reviewed and
sometimes re-written for clarity sake because it was giving me very confusing code. None of the AI code was copy-pasted
without giving it thoughts, and none of the design decisions were made by AI.

I will probably one day fully rewrite the UI code to entirely remove AI involvment to anything beyond research.
