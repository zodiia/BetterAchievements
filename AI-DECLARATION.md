## Notes

### General usage

Outside of UI (see below), AI was primarily used for research and for understanding more advanced C# features (as I had
done very little C# before this), when search engines were incapable of giving me decent results. 

### UI

I'll be real, I don't like UI programming. I didn't like frontend dev before when it was my first job, and I still
don't today. Besides, ImGui gave me more hardships than I'd like to admit it. Therefore, the UI specifically was done
with more AI involvement than in the rest of the codebase. About 1/3 to 1/2 of the UI code has AI involvment beyond
simple research.

As before, it was done responsibly, nothing was ever commited without my own thorough review first (which tbh might have
sometimes taken more time than if I did the whole thing by myself), every single line was read and potentially fixed if 
needs be to more closely resemble what I would have done if it was me typing this code.

None of the UI design choices were made by AI, they're all made from my own ideas and inspiration from other software 
or websites. And neither did AI make any of the code design choices regarding UI (or the rest of the codebase for that 
matter).
